# Overview

Smart Study Planner & Task Manager is a browser-based productivity dashboard that helps students organize assignments and study goals. It allows users to create, categorize, prioritize, search, filter, complete, edit, and delete tasks. Tasks are stored locally in the browser using localStorage.

The purpose of this project is to demonstrate practical JavaScript and browser development skills, including native ES6 array functions, recursion, exception handling, DOM manipulation, event handling, responsive CSS layouts, and integration of a third-party JavaScript library.

[Software Demo Video] https://youtu.be/zKSvPhKHFZY

# Development Environment

I developed this application using Visual Studio Code on Windows.

Technologies and tools used:

- HTML5
- CSS3
- JavaScript ES6 (Vanilla JavaScript)
- Day.js 1.x through the jsDelivr CDN
- Browser DOM API
- Browser localStorage API
- VS Code Live Server for local development and testing
